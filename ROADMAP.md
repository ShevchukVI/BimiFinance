# 📂 BIMI FINANCE PROJECT CARD (v6.0 "SaaS Transition")

**Мета:** Перетворити персонального бота на масштабовану SaaS-платформу з Telegram Mini App, зберігши концепцію "Zero Friction" для користувача.

### 🗺 РОАДМАПА BIMI FINANCE

**✅ Етап 1-2: Автопілот та Smart Receipts (Завершено)**
* Monobank Webhooks, AI-Парсер чеків, AI Інсайти.

**✅ Етап 3: Мікросервіси та Dual-Write (Завершено)**
* Піднято FastAPI + PostgreSQL + React (Vite). База ізольована по `family_id`.

**🚀 Етап 4: Public Onboarding & Security (Поточний)**
* Безпечні інвайт-посилання (Secure Hashes).
* Реєстрація нових сімей без конфліктів.
* Повна відмова від Google Sheets (The Great Migration).

**🎯 Етап 5: BimiApp (React Frontend)**
* Dashboard: Баланси, красиві діаграми, останні витрати.
* Управління скарбничками (Jars) та категоріями.
* Налаштування: Управління учасниками сім'ї, переприв'язка токенів.

**🔮 Етап 6: Унікальні Фічі (The Killer Features)**
* **Smart Utilities (Комуналка):** Трекінг лічильників, баланси рахунків (переплата/борг), математичне прогнозування суми до сплати на основі поточного споживання.
* **Smart Scratchpad (Чернетка):** Спільні сімейні нотатки з автоматичним калькулятором (ввів "М'ясо 500, Пиво 300 / 4" -> бот порахував суму на людину). Захист від спаму (Rate Limiting).
* **Спринти та Планування:** Перенос логіки бюджетування з Sheets в апку.
