# 🏦 BimiFinance (Microservice & Telegram Mini App)

**BimiFinance** — це бекенд та фронтенд частина екосистеми Bimi. Це швидкий, сучасний мікросервіс, який відповідає за зберігання фінансових даних (SaaS) та рендеринг BimiApp.

### 🛠 Стек технологій:
* **Backend:** FastAPI (Python), SQLAlchemy, Pydantic.
* **Database:** PostgreSQL 17.
* **Frontend:** React 19, Vite, TypeScript, Recharts, Telegram WebApp SDK.

---

### 🗺 РОАДМАПА BIMI FINANCE

**✅ Етап 1-3: Мікросервіси та Onboarding (Завершено)**
* Піднято FastAPI + PostgreSQL. Безпечні інвайт-посилання (Secure Hashes).
* Повний переїзд з Google Sheets.

**✅ Етап 4: BimiApp V1 Release (Завершено)**
* [x] **Dashboard:** Баланси, інтерактивні кругові діаграми (Recharts), останні витрати з пагінацією.
* [x] **Скарбнички (Jars):** Створення цілей та прогрес-бари накопичень.
* [x] **Smart Scratchpad:** Сімейна чернетка з автокалькулятором (розумний парсинг валют).
* [x] **Налаштування:** Управління токенами Monobank (шифрування), керування учасниками сім'ї.
* [x] **Редагування:** CRUD операції для транзакцій прямо в UI.

**🚀 Етап 5: Стабілізація та Експорт (Поточний)**
* [ ] Панель фільтрів транзакцій (за датою, категорією).
* [ ] Експорт транзакцій сім'ї у файл CSV/Excel.
* [ ] Celery / APScheduler на бекенді для фонового оновлення балансів Monobank.

**🔮 Етап 6: Унікальні Фічі (The Killer Features)**
* **Smart Utilities (Комуналка):** Трекінг лічильників, баланси рахунків (переплата/борг), математичне прогнозування суми до сплати на основі поточного споживання.
* **Спринти та Планування:** Система бюджетування та лімітів.
