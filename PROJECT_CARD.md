# 🏦 BimiFinance (Microservice & Telegram Mini App)

**BimiFinance** — це бекенд та фронтенд частина екосистеми Bimi. Це швидкий, сучасний мікросервіс, який відповідає за зберігання фінансових даних користувачів (SaaS) та рендеринг Telegram Mini App.

### 🛠 Стек технологій:
* **Backend:** FastAPI (Python), SQLAlchemy, Pydantic.
* **Database:** PostgreSQL 17.
* **Frontend:** React 19, Vite, TypeScript, Recharts, Telegram WebApp SDK.
* **Infrastructure:** Docker Compose, Cloudflare Tunnels.
